# Daily Changelog: 2026-08-14

## Summary of the Session
Se ajustaron los márgenes del footer del tema de Shopify para evitar que el contenido se pegue al borde izquierdo en resoluciones específicas, y se inicializó la vinculación del repositorio con GitHub (`https://github.com/JorgeVexus/Arsenal.git`).

## Detailed Changes

### Componentes y Estilos
- **`assets/screen.css`**: 
  - Se actualizó el padding de `.shopify-section-footer` agregando `var(--rpp)` (margen horizontal global) para evitar que los contenedores `.cols` con margen negativo empujen el texto, redes sociales y copyright fuera del margen del sitio.
  - Se configuró `--content_padding_top: 0px` y `#content { padding-top: 0 !important; }` más `#content > .shopify-section:first-child { margin-top: 0 !important; }` para eliminar el espacio/franja blanca superior entre el menú de navegación y cualquier sección inicial.
  - Se añadió la regla de ruptura de **100vw** (`100% viewport width`) para `.m6bx.wide`, `.m6fr.wide` y secciones con clase `.wide` para garantizar que las secciones en modo ancho/pantalla completa se extiendan de borde a borde sin dejar espacios negros en pantallas grandes.
  - Se añadió la regla CSS global protectora `.r6rt, .fpg-stars, .testimonial-rating, .spr-badge, .spr-starrating { display: none !important; }` para ocultar todas las estrellas de calificación en la tienda.
  - Se añadió la regla CSS global `[class*="cl-card-count"], .collection-count, .products-count { display: none !important; }` para ocultar el conteo de productos en las tarjetas de colecciones.
- **`sections/footer.liquid`**: Se eliminó el `id="shopify-section-footer"` duplicado en el elemento `<nav>` interno para prevenir colisiones de especificidad CSS con el contenedor wrapper generado por Shopify.
- **`sections/arsenal-collection-list.liquid`**: Se eliminó el renderizado del conteo de productos (`cl-card-count`) en la lista de colecciones y se actualizó la opción por defecto en el schema.
- **`snippets/product-item.liquid`**: Se desactivó la asignación por defecto `show_rating` a `false` en las tarjetas de productos.
- **`sections/arsenal-featured-grid-products.liquid`**: Se removió el renderizado de estrellas manuales (`.fpg-stars`) y se actualizó la especificación en schema.
- **`templates/index.json`**: Se removieron los atributos `stars_count` de los bloques de productos destacados y se desactivó `show_product_count`.
- **`templates/list-collections.json`**: Se estableció `"show_product_count": false` en la plantilla de lista de colecciones.
- **`config/settings_data.json`**: Se estableció `"show_product_rating": false` a nivel global en el tema.
- **`sections/arsenal-testimonials.liquid` & `sections/section-testimonials.liquid`**: Se removió el renderizado de estrellas en los testimonios.
- **`sections/timeline.liquid`**: Rediseño completo para dispositivos móviles aplicando principios de Apple Design (carrusel horizontal deslizante con snap inercial, barra navegadora de años flotante con efecto glassmorphic `backdrop-filter: blur(16px)`, respuesta táctil activa instantánea y sincronización en tiempo real vía `IntersectionObserver`), y corrección de la maquetación en escritorio mediante `display: contents !important` en `.timeline-header-mobile` para restaurar la rejilla alternada de 3 columnas sin compresión.
- **`sections/section-video-banner.liquid`**: Se envolvió el bucle de bloques de contenido en un contenedor interno con padding horizontal `max(24px, var(--rpp))` para evitar que títulos, descripciones y botones se peguen a los bordes de la pantalla.
- **`sections/section-rich-text.liquid`**: Se agregó la propiedad y soporte CSS `padding_top_mobile` en la sección y schema.
- **`templates/page.about-us.json`**: Se corrigió el valor `"spacing_mobile"` de la sección rich text que estaba en `-20` a `30px` + `30px` de padding superior.
- **`assets/screen.css`**: Se implementó el padding lateral contenedor para la vista de colecciones (`#shopify-section-main-collection`, `.collection-wrapper`), y se rediseñaron las tarjetas de producto aplicando principios de Apple Design (imágenes a ancho completo `100% width` sin bordes blancos laterales, flechas de navegación de imágenes en tono naranja `#ea5c10`, icono de compra rápida en blanco nítido `#ffffff` permanente en hover, eliminación del espacio libre vertical entre imagen y título, y padding superior en el contenedor de colecciones para evitar colisiones con el menú principal).
- **Configuración de Repositorio**: Se creó `.gitignore` y se configuró el remoto `origin` hacia `https://github.com/JorgeVexus/Arsenal.git`.
