# Daily Changelog: 2026-08-14

## Summary of the Session
Se ajustaron los márgenes del footer del tema de Shopify para evitar que el contenido se pegue al borde izquierdo en resoluciones específicas, y se inicializó la vinculación del repositorio con GitHub (`https://github.com/JorgeVexus/Arsenal.git`).

## Detailed Changes

### Componentes y Estilos
- **`assets/screen.css`**: 
  - Se actualizó el padding de `.shopify-section-footer` agregando `var(--rpp)` (margen horizontal global) para evitar que los contenedores `.cols` con margen negativo empujen el texto, redes sociales y copyright fuera del margen del sitio.
  - Se configuró `--content_padding_top: 0px` y `#content { padding-top: 0 !important; }` más `#content > .shopify-section:first-child { margin-top: 0 !important; }` para eliminar el espacio/franja blanca superior entre el menú de navegación y cualquier sección inicial.
  - Se añadió la regla de ruptura de **100vw** (`100% viewport width`) para `.m6bx.wide`, `.m6fr.wide` y secciones con clase `.wide` para garantizar que las secciones en modo ancho/pantalla completa se extiendan de borde a borde sin dejar espacios negros en pantallas grandes.
  - Se añadió la regla CSS global protectora `.r6rt, .fpg-stars, .testimonial-rating, .spr-badge, .spr-starrating { display: none !important; }` para ocultar todas las estrellas de calificación en la tienda.
- **`sections/footer.liquid`**: Se eliminó el `id="shopify-section-footer"` duplicado en el elemento `<nav>` interno para prevenir colisiones de especificidad CSS con el contenedor wrapper generado por Shopify.
- **`snippets/product-item.liquid`**: Se desactivó la asignación por defecto `show_rating` a `false` en las tarjetas de productos.
- **`sections/arsenal-featured-grid-products.liquid`**: Se removió el renderizado de estrellas manuales (`.fpg-stars`) y se actualizó la especificación en schema.
- **`templates/index.json`**: Se removieron los atributos `stars_count` de los bloques de productos destacados.
- **`config/settings_data.json`**: Se estableció `"show_product_rating": false` a nivel global en el tema.
- **`sections/arsenal-testimonials.liquid` & `sections/section-testimonials.liquid`**: Se removió el renderizado de estrellas en los testimonios.
- **Configuración de Repositorio**: Se creó `.gitignore` y se configuró el remoto `origin` hacia `https://github.com/JorgeVexus/Arsenal.git`.
